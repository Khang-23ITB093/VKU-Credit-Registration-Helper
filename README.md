# VKU Credit Registration Helper

Extension Chrome hỗ trợ đăng ký tín chỉ cho sinh viên VKU, giúp quá trình đăng ký học phần trở nên dễ dàng và hiệu quả hơn.

## Tính năng hiện tại

### Đã hoàn thành
- 🔍 **Tìm kiếm học phần**
  - Tìm kiếm theo mã học phần hoặc tên học phần
  - Giao diện multi-select hiện đại với Choices.js
  - Lưu và khôi phục lựa chọn khi mở lại popup

- 📋 **Xem chi tiết học phần**
  - Xem tất cả học phần trong một tab mới
  - Xem chi tiết các học phần đã chọn
  - Tự động mở trang đăng ký trong tab mới
  - Hỗ trợ nhiều domain (daotao, dk1, dk2)

### Đang phát triển
- 🗑️ **Quản lý học phần đã đăng ký**
  - Xem danh sách học phần đã đăng ký
  - Xóa học phần khỏi danh sách
  - Cập nhật trạng thái học phần

- 📅 **Thời khóa biểu**
  - Hiển thị thời khóa biểu cho các học phần đã chọn
  - Tùy chỉnh màu sắc và bố cục
  - Xuất thời khóa biểu

- 🎨 **Cải thiện UX/UI**
  - Thiết kế lại giao diện popup
  - Thêm animations và transitions
  - Tối ưu hóa cho mobile
  - Thêm dark mode

## Cài đặt

1. Clone repository:
```bash
git clone https://github.com/your-username/vku-credit-registration.git](https://github.com/Khang-23ITB093/VKU-Credit-Registration-Helper.git
```

2. Cài đặt extension trong Chrome:
   - Mở Chrome và truy cập `chrome://extensions/`
   - Bật "Developer mode"
   - Click "Load unpacked" và chọn thư mục extension

## Sử dụng

1. Truy cập trang đăng ký tín chỉ VKU
2. Click vào icon extension để mở popup
3. Sử dụng các tính năng:
   - Tìm kiếm học phần
   - Xem chi tiết học phần
   - Xem thời khóa biểu (đang phát triển)
